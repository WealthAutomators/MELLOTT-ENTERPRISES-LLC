## Development

```bash
npm install
npm run dev
```

## Scripts

- `npm run images:products` — download product images via Unsplash Search API (requires `UNSPLASH_ACCESS_KEY`)
- `npm run images:unsplash` — download curated Unsplash assets by photo ID
- `npm run images:homepage` — download homepage imagery
